- [x] **Fase 3 — Chaos / falhas reais** · concluída (17/set/2026)
  - Suíte revalidada (`docker compose --profile tests run --rm integration-tests`, imagem
    `tests` reconstruída): 3/3 suites, 14/14 testes, `LOAD rejected: 0`. T1–T6 verdes.
  - Falhas reais na produção local (usuário real ponta a ponta + conferência no Mongo):
    Redis down, Mongo down, restart do app, restart de worker, recuperação pós-falha.
    - Redis down: liveness 200; readiness 503 fail-fast (~0,3s, breaker OPEN) **após fix**;
      operações seguem funcionando (cache degrada, Mongo responde); recupera em ~9s.
    - Mongo down: liveness 200; readiness 503 imediato; escrita fail-closed sem estado
      parcial; recupera em ~15s.
    - Restart do app: healthy em ~12s, saldo/ledger intactos, depósito 201.
    - Restart de worker: reconecta Mongo/Redis, recovery scan limpo, saque novo OK e replay
      deduplicado (sem débito duplo).
  - **Defeito real corrigido (fail-slow do Redis)**: ioredis com defaults
    (`enableOfflineQueue: true` + retry infinito) enfileirava comandos para sempre com o
    Redis fora → `/readiness` e requests (flushWalletCache pós-depósito) penduravam (o
    depósito commitava atômico, mas a resposta nunca voltava). Fix em
    `RedisClient.getRedis()`: `enableOfflineQueue:false`, `maxRetriesPerRequest:1`,
    `connectTimeout:2000`, `commandTimeout:2000`; regressão em `RedisClient.test.ts`.
  - **Sem corrupção financeira** em nenhum cenário (saldo + ledger conferidos no Mongo).
  - Unit: **896 passed / 0 failed** (17 skipped = integração real desligada no host).

## Como retomar / comandos úteis

- Suíte unit no host (condição CI; evita `EAI_AGAIN redis`):
  `node /tmp/opencode/jest-host.cjs --silent` (wrapper que força `NODE_ENV`/
  `BACKBET_RUNTIME_ENV=test` e reescreve o host do `REDIS_URL` para o endpoint publicado;
  recriar em `/tmp/opencode/jest-host.cjs` se o tmp foi limpo).
- Suíte de integração real (dentro da rede do compose):
  `docker compose --profile tests run --rm integration-tests`
  (após mexer em `src`, **rebuildar**: `docker compose build integration-tests`).
- Carga de CONTENÇÃO (mesma carteira): `node scripts/load-driver.cjs 1 2 5 10`.
  - **Atenção**: 5x demora ~60min (depósitos single-carteira estouram 1800s) — teto conhecido.
- Carga DISTRIBUÍDA (carteiras distintas): `node scripts/load-driver.cjs --distributed 1 2 5 10`.
  - Escala 10x leva ~20min só de wall (25000 dep + 25000 saques + 8000 apostas), tudo verde.
  - Requer `docker compose build integration-tests` após mudanças em `src`.
- Rebuild de produção quando mexer no Dockerfile: `docker compose build backbet` (faz `target: runtime`).
- Suíte direta `npm test` no host falha 8 suítes por timeout (hostnames internos), não por regressão.
