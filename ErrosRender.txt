Erros Detectados

Ausência de declarações de tipos para vários módulos de terceiros (newrelic, express, express-serve-static-core, cors, swagger-ui-express, swagger-jsdoc, qs, jsonwebtoken), resultando em TS7016/TS2307 espalhados por index.ts, src/infrastructure/api/**/*, JwtService.ts, http.ts etc.
AuthenticatedRequest/RequestWithContext definidos em http.ts não estendem corretamente express.Request, portanto o compilador não reconhece propriedades padrão (headers, body, params, query, method, originalUrl, route, ip, path) em ApiServer.ts, controllers e middlewares.
Handlers com parâmetros sem tipo explícito (p.ex. origin, callback no CORS config em ApiServer.ts:87, _res/next no fallback de rotas em routes/index.ts:63) disparando TS7006.
cacheMiddleware.ts e outros middlewares acessam req.query/req.params sem que os tipos generics de AuthenticatedRequest incluam esses campos, gerando TS2339 adicionais.
Correções Recomendadas

Instalar e declarar como devDependencies os pacotes de tipos necessários:
npm i -D @types/newrelic @types/express @types/express-serve-static-core @types/cors @types/swagger-ui-express @types/swagger-jsdoc @types/qs @types/jsonwebtoken.
Garantir que tsconfig.json (campo types) inclua esses pacotes ou que o projeto use a resolução padrão (não excluí-los via typeRoots).
Atualizar http.ts para que RequestWithContext e AuthenticatedRequest estendam express.Request<Params, ResBody, ReqBody, ReqQuery, Locals> preservando headers, body, params, query, method, originalUrl, etc.; exportar helpers genéricos para os controllers/middlewares usarem.
Revisar AuthenticatedRequest usos nos controllers (BetController, FinanceController, UserController, WalletController, etc.) e fornecer argumentos generics adequados (ex.: AuthenticatedRequest<{ betId: string }, BetResponse, PlaceBetBody>).
Tipar explicitamente callbacks e parâmetros anônimos:
• origin: string | undefined e callback: (err: Error | null, allow?: boolean) => void no middleware CORS (ApiServer.ts:87).
• _res: Response / next: NextFunction no handler 404 de routes/index.ts:63.
Confirmar que cacheMiddleware.ts (linhas 81-82) declara o generic AuthenticatedRequest<ParamsDictionary, unknown, unknown, ParsedQs> ou desestrutura req usando o tipo correto após ajustar AuthenticatedRequest.
Após aplicar as correções, rodar npm install, npm run build localmente e confirmar que o deploy no Render recompila sem erros.
