⚡ COMO TESTAR
═══════════════════════════════════════════════════════════════════════════

1. Compilar:
   $ npm run build

2. Iniciar Servidor:
   $ npm start
   
3. Registrar Usuário:
   $ curl -X POST http://localhost:3000/api/auth/register \
     -H "Content-Type: application/json" \
     -d '{
       "email":"test@ex.com",
       "firstName":"T","lastName":"U",
       "username":"tu","password":"Pass123!"
     }'

4. Usar Bearer Token:
   $ curl -H "Authorization: Bearer <USER_ID>" \
     http://localhost:3000/api/auth/me
