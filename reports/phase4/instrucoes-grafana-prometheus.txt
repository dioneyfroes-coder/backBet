Grafana Dashboard

Abra Grafana → Dashboards → New → Import.
Cole o conteúdo de dashboard.json (ou faça upload), selecione o datasource Prometheus usado no ambiente real (substitui ${DS_PROMETHEUS}), salve como “BackBet - Observability”.
Valide cada painel: use o time picker para “Last 15 minutes” e confirme que backbet_* séries aparecem; ajuste as variáveis/labels caso os ambientes usem rotas diferentes.
Alertmanager/Prometheus Rules

Copie alerts.yaml para o repositório de infraestrutura (por exemplo alert-rules/backbet.yaml).
Se estiver usando Prometheus plain: adicione o arquivo em rule_files e recarregue (curl -X POST http://prometheus:9090/-/reload). Para Prometheus Operator, crie um PrometheusRule apontando para o mesmo conteúdo.
Teste cada alerta:
Latência: force uma simulação aumentando artificialmente o tempo de resposta (>1s) e confira no Alertmanager.
Erro 5xx: gere respostas 500 numa rota específica para validar a razão >2%.
Cache errors: derrube o Redis temporariamente ou incremente backbet_cache_errors_total para observar o firing.
Verifique que os labels service e severity roteiam para os canais esperados (Slack, PagerDuty etc.).
