# CoinFlip - Aposta múltipla (batch)

## Como funciona

O endpoint `/api/games/coin-flip/play-batch` permite que o usuário envie várias escolhas (cara ou coroa) em um único request. O backend executa cada rodada sequencialmente, registra todas as jogadas e retorna:
- O resultado de cada rodada
- O saldo final (soma de perdas e ganhos)

## Exemplo de request

```json
POST /api/games/coin-flip/play-batch
{
  "choices": ["HEADS", "TAILS", "HEADS"]
}
```

## Exemplo de resposta

```json
{
  "rounds": [
    { "result": "WIN", ... },
    { "result": "LOSE", ... },
    { "result": "WIN", ... }
  ],
  "totalPrize": 6.0
}
```

- O campo `totalPrize` já considera o valor apostado e o prêmio de cada rodada.
- O valor de aposta é sempre o valor fixo configurado no backend.

## Observações
- O saldo do usuário é verificado antes de cada rodada.
- Todas as rodadas são registradas normalmente no histórico.
- O endpoint é protegido por autenticação.
