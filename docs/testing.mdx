# Testes e Execução Local

Este documento reúne comandos e dicas para executar testes e visualizar a documentação localmente com Docusaurus.

## Rodando os testes (Jest / ts-jest)

O projeto usa `jest` com `ts-jest`. Para executar toda a suíte:

```bash
npm install
npm test
```

Para rodar apenas testes do módulo de betting:

```bash
npm test -- --testPathPattern=betting
```

Se você precisar rodar um arquivo de teste específico com watch:

```bash
npm test -- --watch src/core/betting/domain/services/__tests__/BetService.test.ts
```

## Observações sobre mocks Mongoose

Ao mockar repositórios Mongoose nos testes, atente que chamadas como `Model.findOne().lean()` são encadeadas — o mock deve retornar um objeto com `.lean()` que resolve para o documento esperado.

Exemplo de stub Jest:

```ts
jest.spyOn(Model, 'findOne').mockReturnValueOnce({ lean: jest.fn().mockResolvedValue(fakeDoc) } as any);
```

## Visualizar docs com Docusaurus (guia rápido)

Este repositório contém os arquivos de documentação em `docs/` compatíveis com Docusaurus v2. Se você ainda não tem um site Docusaurus inicializado, siga:

1. Crie um site Docusaurus (diretório `website` ou `docs-site`):

```bash
npx create-docusaurus@latest docs-site classic
cd docs-site
```

2. Copie os arquivos `docs/*.mdx` deste repositório para `docs-site/docs/`.
3. Ajuste `docs-site/sidebars.js` ou use a opção de sidebars automáticos.
4. Instale dependências e execute:

```bash
npm install
npm run start
```

O Docusaurus abrirá uma página local, recarregável, onde os arquivos `docs/*.mdx` serão renderizados.

## Checklist antes de PR

- Verifique se os novos `docs/*.mdx` têm `title`, `slug` e `sidebar_label` adequados.
- Confirme que links relativos apontam para arquivos existentes.
- Rode `npm test` para garantir que nenhuma alteração do docs impactou teses (ex.: imports relativos usados por scripts de build).
