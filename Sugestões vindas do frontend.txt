Sugestões de endpoints / contrato backend (caso ainda não existam)

Notifications: PUT /users/me/notifications — body: { [prefId]: boolean }, retorna 200 com as preferências atualizadas.
Security:
Change password: POST /users/me/password — body: { currentPassword, newPassword }.
Delete account: DELETE /users/me.
Profile:
Pix key: já usado usersApi.updatePixKey({ pixKey }) — manter.
Documents upload: POST /users/me/documents (aceitar FormData).
Wallet:
Withdraw: POST /wallets/withdraw ou via payments client requestPixWithdrawal.
Deposit: POST /wallets/deposit e endpoints de status para checagem do pagamento.
Loja:
Items: GET /store/items — retornar lista de produtos com { name, description, price, id, ... }
